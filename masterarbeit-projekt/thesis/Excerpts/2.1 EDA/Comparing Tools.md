# COMPARING TOOLS PROVIDED BY PYTHON AND R FOR EXPLORATORY DATA ANALYSIS

# Definition EDA S.131

Die ersten Schritte einer EDA umfassst eine gründliche Erfassung der Daten, indem aussagekräftige Hinweise wie vermutete Muster, Anomalien sowie ermittelte Hypothesen getestet und Annahmen mithilfe deskriptiver Statistiken und grafischer Werkzeuge überprüft werden. --> Klare Definition von EDA mit konkreten Bestandteilen

# EDA ist iterativ (S.131)

EDA ist kein Ein-Stopp Prozess sondern es hat multiple Prozesse, bis die Daten mehr und mehr klar werden, um was es geht. --> Begründet warum Experiment 3 (iterative Interaktion) sinnvoll ist

# Die 6 Schritte von EDA (s.131.132): Relevanz für die Referenzanalyse

1. Attribute verstehen
2. Univariate ANalyse der Daten
3. Zusammenhänge zwischen den Attributen verstehen
4. Auffällige Muster erkennen
5. Ausreißer erkennen
6. Feature Engineering
